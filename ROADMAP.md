# Roadmap

| Phase | Outcome | Gate |
|---|---|---|
| 0 — Foundation | Standalone bilingual portal, documented scope, GitHub review trail, Vercel preview. | Founder reviews the exact commit and content. |
| 1 — Community definition | Define membership promise, community rules, moderation, safeguarding, participation path, owner, measures, timeline, and tool costs. | Founder approves the operating model before member data or accounts are introduced. |
| 2 — Participation pilot | Add one approved path such as event signup or a moderated interest form, with a clear data policy and owner. | Validate the pilot with a small invited group. |
| 3 — Community features | Consider member profiles, discussion, project showcases, learning paths, and partner contributions based on pilot evidence. | Each feature has a purpose, workflow, success measure, cost, and support owner. |
| 4 — Public launch | Connect `www.ai-generation.my`, verify DNS/TLS, accessibility, content, and support ownership. | Andrew approves the release commit and launch checklist. |

Dates and costs for phases 1–4 are intentionally uncommitted until the operating model and requirements are agreed.
